## Sole sync owner (hard requirement)

`Cap30VerticalHintGuideHost` remains the **only** Browse-pane
`syncCap30BrowseReady` call site. Tip Host observes epoch / chrome only.
Vertical Host must stay mounted for the Browse pane lifetime with **no**
`activeChrome` gate — see class comment (aligned with Cap 30.3 shared
orchestrator singleton hard requirement).

## Create tap during `<2>` (Accepted risk)

On **Full**, Create remains hittable (`IgnorePointer` on tip). Tapping
opens `BuildPoolScaffoldPage` via `Navigator.push`; Browse pane / tip Host
are **not** disposed. The tip timer (**3.5s** / `kCap30CreatePoolTipDuration`)
**keeps running under Build**.
User may return with tip already gone and `diskStep == 3` (no `<2>`
replay). 30.4 does **not** cancel / pause / roll back on covering route.

On **Limited**, Create is disabled — this path is Full-only; tip still
shows while Create is disabled (ADR-060 D4).
