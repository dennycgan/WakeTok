## Adoption wording (canonical)

300ms adopted as production default. Cancel mechanism (leave-cancel,
single networked prepare path) unchanged from Cap 16; this change
only increases invocation frequency. One real-usage session (owner,
mixed mood simulation) observed the guard suppressing 91.7% of leaves
before prepare start; the single leak window observed clean cancel
behaviour (no silent delivery). Sample size (n=1 leak event) does not
establish a statistical failure rate — this is a qualitative "no
hard-failure signal observed" pass, not a validated percentage.
System-level cost (battery/thermal/throttling) remains unmeasured.
Single-owner, single-device sample.
