# Cap 20.5b — Double-tap to exit persistent magnification

> **Status:** Complete (Kafka Profile smoke PASS, 2026-09-05).
> Work commit: `66fc463`.

## Positioning

**20.5b is a new phase**, inserted between **20.5** and **20.6** (same
pattern as Cap **19.5b**). Cap 20.5 Live motion Host coverage remains
closed. 20.6 / 20.7 numbers are **not** renumbered.

**Scope:** still / Live-static Layer-2 only
(`MagnificationHostMode.still` + magnified). Same gate family as Reset.
Video / transient Host modes untouched.

**Not in scope:** ADR-043 Decision 3 / D7 **double-tap to enter** zoom
(still Out). Fit-state double-tap is a no-op.

## Implementation (work `66fc463`)

- Hand-written pointer state machine on existing
  `MagnificationPointerHost` `Listener`.
- **No** `GestureDetector.onDoubleTap` /
  `DoubleTapGestureRecognizer` (avoids ~300ms tap disambiguation delaying
  single-finger pan — soak check aligns with `T-20.5b-5`).
- Action: same `browseMagnificationProvider.notifier.forceFit()` as Reset
  (no separate animation).
- Constants: up→down interval ≤350ms; down–down slop ≤24px; max press
  ≤500ms; move cancel ~18px; ≥2 fingers clears candidate.
- Candidate clear on `hasActiveMagnification` falling edge (Reset /
  leave / Cap 19 panel / Live rising-edge forceFit) — one clear point.
  Guard: `T-20.5b-8` (fake clock kept inside the 350ms window so the
  assert is “cleared”, not “timed out”).

## Kickoff long-press vs double-tap (verified non-conflict)

Kickoff MVP “long-press media (non-chrome) → album panel” is **not** a
live recognizer in Cap 20.5b:

- Cap 19 / ADR-040 **Decision 15** replaced that entry with the fixed
  bottom-trailing icon → half-sheet (`cap19_entry_icon` /
  `cap19_actions_half_sheet`).
- `lib/` has **zero** `onLongPress` / `LongPressGestureRecognizer`
  usages (grep at design freeze).
- ADR-040 **Decision 17** keeps Photos-style Live long-press replay Out
  (gesture slot unused).

Therefore the Cap 20.5b Host double-tap state machine does **not** add a
long-press exclusion branch. Do not re-arm “kickoff long-press still
lives” from the private kickoff text alone.
