## Design records (pre-implementation)

### Session zero-touch / ADR-I passive guarantee

Cap 19.5 must not refresh Session Queue or Snapshot after `listAssetSources`
or `addAssetToAlbum`. That discipline is **not** only “this phase’s code
review says we did not call `browseSessionProvider`” — it rests on a stronger
architectural fact:

**ADR-I Queue Stability is implemented passively.** Cap 13.1 / **ADR-023
D7=A** freezes Snapshot/Queue as outcomes that do **not** auto-mutate on
library changes. The rejected alternative **“Photos observer no-op for
Stability” (D7=B)** was explicitly declined as over-engineering vs ADR-I
passive wording; Cap 13 does **not** install a `PHPhotoLibraryChangeObserver`
solely to no-op (and the Host tree has no Photos change observer today).

Therefore: if 19.5 append/list paths avoid explicit
`browseSessionProvider` / `browseSnapshotCacheProvider` invalidation, **no
hidden listener** should turn a PhotoKit write into a session rebuild. **W-19.5-7**
(widget test: session/`roundEpoch` unchanged after append) is the regression
guard for explicit calls; the passive stack is the reason that guard is
expected to stay stable (not flaky from background observers).

**Future warning:** If a later phase adds a Photos library change observer
(or any automatic Snapshot/Session rebuild on external album mutation),
re-evaluate 19.5’s no-refresh assumption and Cap 19 panel/left-swipe
behaviour before shipping that observer.

### kickoff §14 — Generated Clip Source backing album (ADR-J §5) — N/A this phase

kickoff §14 states that a **Generated Clip Source backing album** is an
ordinary writable User Album that **may appear** in the Add-to-Album list;
appending ordinary content has ADR-J §5 consequences (that Pool loses Pure
status on the next Session).

**Clips is not implemented** (`lib/features/clips/`, export jobs, etc. are
absent). No such backing albums exist in the library yet, so 19.5’s writable
User Album list will contain only normal user-created albums. **This phase
does not filter or special-case backing albums or wire ADR-J §5.**

When Clips lands, revisit whether 19.5’s list filter must recognise backing
albums and surface ADR-J product consequences.

  barrier ~28%; immersive dark + `onMedia` copy.

  (W-19.5-7).
