### Manual steps (abbrev)

**Prep:** Profile build from `main` at/after `c3b5a58`. Full Access except
LIMITED row. Browse → All (or any Pool with assets).

1. **GEO** — eyeball column order.  
2. **STILL / VIDEO / LIVE** — tap Share → sheet → swipe dismiss → no toast.  
3. **ICLOUD** — cloud-only item → no Cap 23 dialog → Share → record sheet / system download / Share-only fail toast.  
4. **LIMITED** — Settings → WakeTok → Photos → Limited; force-quit → relaunch; authorized asset → Share visible.  
5. **CANCEL** — dismiss sheet; zero toasts.  
6. **SHARE-OK (optional)** — complete one target; silent return.  
7. **MISS** — external-delete current → Share → Cap 23; dismiss → tap again → dialog again.  
8. **L2** — find non-L2-ready actionable item if any; else SKIP.  
9. **OPT** — record optical note only.  
10. **FAIL** — SKIP unless opportunistic.
