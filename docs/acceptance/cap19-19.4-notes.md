## Implementation notes

- **Icon placement:** `MainBrowseShellPage` overlay `Stack`; rendered only when
  `destination == browse` (not Clips / Auto / Settings).
- **Y inset:** shell-fixed constant `kMainBrowseScrubberReserveHeight (48) +
  kCap19EntryIconAboveScrubberGap (40)` — does **not** vary by feed page media
  type (avoids icon jump while scrolling).
- **Half-sheet:** `showModalBottomSheet`; Limited = `AbsorbPointer` D4 row +
  Settings button; Full = disabled `ListTile` placeholder (picker deferred to
  **19.5**). No `listAssetSources` / no bootstrap on open.
- **ADR-040 D15 read (product vs ADR literal):** D15 requires the entry icon
  to remain visible regardless of Photos authorization level (Limited and Full
  both show it on Browse). **Cross-destination visibility** (icon only on Browse,
  hidden on other bottom-nav tabs) is a **Cap 19.4 product choice** — not an ADR
  literal requirement that the icon appear on every Main Browse shell destination.
