## Why not reuse `LimitedAccessBanner` type

Full needs a status-only branch. Also: shell **W-4** (`main_browse_shell_test`: Limited, tap Settings, `find.byType(LimitedAccessBanner)` → `findsNothing`) would fail if Settings mounted that type. permission_ui **W2** / **W6** also assert no banner on Browse (default destination). (permission_ui **W4** is Restricted title — unrelated.)

Note: Flutter 3.41 `IndexedStack` wraps inactive children in `Visibility(maintainSize/State/…)`. That is not identical to a bare “always onstage” Stack, but Settings-as-current still exposes any banner type to finders — shell W-4 is the decisive guard.
