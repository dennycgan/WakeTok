### Manual — P-19.6-SWIPE + GUIDE

1. Cold start Debug → Full Photos → Browse tab.
2. Confirm centered guide card (left arrow, title + subtitle) ~2.5s.
3. Swipe to a still or video; left-swipe in media center.
4. Photos → WakeTok album → membership visible.
5. Top toast; no feed jump.
6. Kill app → guide shows once again; switch to Settings and back in same session → guide absent.

## Host note (duplicate album)

`PhotoLibraryService.createAlbum` finds an existing user album by title
(case-insensitive; min `localIdentifier` on ties) before creating — reduces
reinstall / Limited create-only duplicate `"WakeTok"` albums. Debt **445**
(title uniqueness) remains Accepted (permanent); this is Host reuse, not
list-find under Limited.
