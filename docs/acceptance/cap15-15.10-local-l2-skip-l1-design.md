## 0. Problem statement

When Layer 2 is **already obtainable** (local file or prior successful L2 in
this Browse Session), the feed still shows **Layer 1 blur** (+ video corner
spinner) before sharp still or playback. Owner observation (Kafka 2026-08-22):
two directly-playable videos with a blur-only neighbour between them is **not**
the doom-scroll target and blocks a clean **393** probe matrix.

**Not in scope:** 400 (no L1 at all), 393 (shared PV wrong A/V at settle), 395
(restart-from-0 after slot taken).

## 1. Historical constraint — no public “local before L2” API

### Known debt (STATE)

> List-time availability via undocumented PHAssetResource KVC
> `locallyAvailable` | No public isLocallyAvailable on PHAsset/PHAssetResource
> in the iOS SDK

### What the codebase already does

`PhotoLibraryService.mapAvailability` uses KVC `locallyAvailable` **only for
list-time** catalog mapping (`AssetAvailabilityDto`). Comments forbid heavy
sync image requests on the list path. Pickup for product feed gating is
**Final hardening**, not Cap 15.

The **Main Browse feed** today carries **asset ids only** in the Session queue —
no per-item `AssetAvailability` on become-current.

### Design conclusion (Q1 — scope)

| Option | Verdict |
|--------|---------|
| **A. Revisit after L2 success in this Session** | **In scope for 15.10 v1.** App-owned “L2-ready” memory does not need PhotoKit pre-check. |
| **B. First visit skip L1 because “Host knows local before any L2 request”** | **Out of scope for 15.10 v1** without either (i) adopting undocumented KVC on the product path + wiring list availability into feed (explicit owner re-board of the Known debt row), or (ii) speculative L2-before-L1 (reopens ADR-025 layering and Cap 16 cancel semantics). |
| **C. ±1 Page State only (no Session cache)** | **Insufficient alone** — scroll >1 away destroys State; `_retryLayer2Only()` still blur-first while re-fetching L2 even within ±1. May complement A but does not replace Session memory. |

**Locked v1 product scope:** **Session-scoped L2-ready skip L1 on second and
later become-current** for the same `localIdentifier` **within the same Browse
Session** (same Cap 14 Session / IndexedStack lifetime; ends on leave Browse per
ADR-027).

First visit continues ADR-025 L1→L2 unless a **future** phase explicitly adopts
list-time KVC or another ADR.

## 3. Still vs video

| Media | L2-ready proof (v1) | Target UX on revisit |
|-------|---------------------|----------------------|
| **Still** | Prior become-current applied `FeedPageMedia.still(..., layer: full)` for this id in Session | **Sharp still immediately** — no blur flash, no L1 re-fetch |
| **Video** | Prior become-current reached playable video L2 (`FeedPageMediaKind.video` + prepare completed) for this id in Session | **Fast path skips Layer 1 local preview request + dwell only.** Token does **not** mean “AVPlayer is still alive” (1+1 pool may have evicted it). On revisit: **skip** `requestPreview` blur path; **still** run `requestPlayableVideo` / prepare if needed; **keep poster mounted** (from token: last known full-quality poster / L2 still frame) **until** `onSurfaceReady` — same safety net as 15.6b/15.7. **Forbidden:** become-current fast path with **no** on-screen cover during native re-prepare (blank/black gap). |

**First visit (no proof):** unchanged L1→dwell→L2.

## 4. Dwell (Cap 16.4)

When Session L2-ready fast path runs, **bypass Layer 2 dwell** (`bypassDwell:
true` — same mechanism as Retry). Rationale: dwell exists to avoid canceling
slow iCloud prepares; proven local revisits should not wait 500 ms on blur.

**Invariant:** First visit and iCloud-unproven paths **keep** dwell.

## 5. Session L2-ready memory — proposed shape

### 5.1 What to remember (not bytes on disk)

Per Browse Session, a **bounded map**:

`localIdentifier → L2ReadyToken`

Token carries **only what replay needs in-process**:

- kind (still full display handle / video prepare generation or repo token)
- **generation** tied to Cap 16 cancel / display gate
- **no duplicate networked fetch** if token still valid

**Explicit non-goal:** Do **not** add a new persistent on-disk cache directory.
Reuse existing Layer 2 artifacts only while Host/Dart contracts already hold
them. Token **survives leave-current** once L2 has completed; see §5.2.

### 5.2 Lifecycle

| Event | Action |
|-------|--------|
| L2 **success** on become-current | Insert / refresh token for id (include still full display handle or video poster reference for on-screen cover during revisit prepare) |
| Leave current while L2 **still in flight** (incomplete) | Cap 16 leave-cancel runs as today. **Never mint a token** for this visit — there is no “ready” to remember. (Not “create then invalidate”; simply **no token**.) |
| Leave current after L2 **already succeeded** | **Token stays valid.** Leave-cancel still runs for any **new** in-flight work on the item being left, but must **not** erase Session L2-ready proof — that is the whole point of revisit skip. |
| Leave Browse (Session end) | Clear entire map |
| Tab switch ending Session (ADR-027) | Clear map |
| Failed / cancelled L2 (never reached success) | No token |

### 5.3 ±1 Page State

When page widget still mounted **and** Session token valid, promote may use
token without cold L1. When widget cold but token valid, Session path still
applies.

## 6. Cap 16 non-regression (mandatory invariants)

Cap 16 fixed real storage leak (+7 GB class) via leave-cancel + one networked
load + dwell. **15.10 must not reopen that path.**

### Hard invariants (same language as ADR-031 three-axis / 15.5 notes)

1. **Networked Layer 2:** No extra `requestDisplayAsset` / `requestPlayableVideo`
   / prepare calls versus today for the same scroll pattern. Revisit fast path
   **reuses** prior success; **never** a second network fetch “because cache.”
2. **Device storage:** No new durable files; no extended lifetime of temp JPEG /
   AVAsset beyond existing contracts. Session map holds **handles/metadata only**
   (poster path / display reference for cover during revisit prepare).
3. **Cancel semantics:** Leave-cancel on swipe-away **still required** for
   in-flight Layer 2 on the item being left. **Do not** mint L2-ready tokens
   from partial / cancelled downloads. **Do not** invalidate tokens minted from
   **completed** L2 when the user leaves that item — revisit skip depends on
   that persistence until Session end.

### Verification (15.10 acceptance)

- Re-run **16.5-style** Videos M7 (~80 flicks, no Instruments) on Kafka after
  15.10 work — record **numbers** (Total / Photos / iOS / 系统数据).
- Owner + logs: no duplicate `layer2_load_start` for same id become-current
  when token valid (widget test + device spot check).
